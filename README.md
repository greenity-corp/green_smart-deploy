# GreenSmart 릴리즈 안내

이 저장소는 GreenSmart의 **공개 릴리즈 안내 페이지**입니다. 배포 자동화나 운영 설정을 보관하지 않으며, 이 저장소에서는 통합 제품 릴리즈를 게시하지 않습니다. 현재 정식 제품 릴리즈는 없습니다.

| 구성요소 | 전용 릴리즈 목록 | 현재 상태 |
|---|---|---|
| Cloud | [Cloud Releases](https://github.com/greenity-corp/green_smart-cloud-releases/releases) | 제품 릴리즈 없음 |
| Edge | [Edge Releases](https://github.com/greenity-corp/green_smart-edge-releases/releases) | 제품 릴리즈 없음 |
| Controller | [Controller Releases](https://github.com/greenity-corp/green_smart-controller-releases/releases) | 제품 릴리즈 없음 |

Cloud·Edge·Controller는 각각 다른 제품 구성요소입니다. **각 저장소에는 해당 구성요소의 출고 파일과 안내만** 게시합니다. 서로 다른 구성요소의 파일을 한 릴리즈에 묶지 않습니다. 함께 사용할 수 있는 버전은 개별 릴리즈 설명에서 상대 릴리즈의 버전과 링크로 확인합니다. 설치 전에는 해당 릴리즈의 호환성, 체크섬, 서명 및 복구 안내를 확인하세요.

개발 코드, Terraform 계획·상태, 운영 문서, 인증정보, 내부 시험 자료는 네 공개 저장소 어디에도 게시하지 않습니다. 구성요소 자체 시험, 통합 QA, 보안·설치·복구 검증과 출고 승인이 끝나기 전에는 제품 릴리즈를 만들지 않습니다.
