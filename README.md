# GreenSmart 릴리즈

이 저장소는 GreenSmart 플랫폼의 **공개 릴리즈 전용 공간**입니다. 현재 정식 제품 릴리즈는 게시되지 않았습니다. 저장소 이름에 `deploy`가 남아 있지만 배포 자동화나 운영 설정을 보관하지 않습니다.

## 게시 대상

출고 승인을 받은 버전의 설치·업데이트 안내, 변경 이력, 배포 파일, SHA-256 체크섬, 서명 검증 방법, 소프트웨어 구성 명세(SBOM)와 출처 증거만 게시합니다. 개발 코드, Terraform 계획·상태, 운영 문서, 인증정보, 내부 시험 자료는 게시하지 않습니다.

## 릴리즈 기준

각 릴리즈는 검토된 개발 소스 커밋과 정확한 빌드 결과에 연결합니다. Cloud·Edge·Controller의 자체 시험, 통합 QA, 설치·복구·보안 검증과 출고 승인을 거친 파일만 공개합니다. 검증이 끝나기 전에는 릴리즈 태그나 다운로드 파일을 만들지 않습니다.

배포 파일을 사용할 때에는 해당 버전의 설치 문서와 호환성 표를 확인하고, 서명과 체크섬을 검증하세요. 현장 장치 제어 기능은 별도 안전 검증 및 승인 범위에 따릅니다.
